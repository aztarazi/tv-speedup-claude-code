# Ускоряем Android TV с помощью Claude Code и ADB

Промпт для Claude Code, который помогает разгрузить Android-телевизор: отключает фоновые службы и предустановленные приложения. Через ADB, без root.

Перед изменениями сохраняет исходные настройки и показатели памяти, а также подготавливает команды для отката.

## Что понадобится

- Компьютер с установленным Claude Code
- Телевизор на Android TV в одной локальной сети с компьютером
- Включенный режим разработчика и настроенное подключение ADB

Чтобы включить режим разработчика, обычно нужно открыть настройки телевизора, перейти в раздел "Об устройстве" и семь раз нажать на номер сборки. Затем в параметрах разработчика включить соответствующую отладку.

Путь к настройкам и способ подключения по сети могут отличаться в зависимости от модели и версии Android TV.

## Как пользоваться

1. Откройте файл [PROMPT.md](PROMPT.md) и скопируйте текст промпта
2. Укажите модель и IP-адрес своего телевизора
3. Вставьте промпт в Claude Code
4. Следите за выполнением команд и подтверждайте необходимые действия

При первом подключении может потребоваться разрешить отладку на телевизоре.

## Что такое ADB

ADB (Android Debug Bridge) входит в штатные инструменты Android и позволяет управлять устройством с компьютера через командную строку.

Для описанной оптимизации не требуются root, перепрошивка или разблокировка загрузчика.

Промпт предназначен для Android TV. На LG (webOS) и Samsung (Tizen) не проверялся.

## Что делает промпт

- Сохраняет исходные настройки, список установленных пакетов и показатели памяти
- Подготавливает скрипт для отката изменений
- Отключает ненужные приложения и службы через `pm disable-user`, не удаляя их
- Учитывает критические компоненты системы, включая пульт, клавиатуру и сервисы Google Play
- Уточняет, какие функции вы используете: стриминг, голосовой ассистент, Chromecast и обновления
- Проверяет состояние телевизора после изменений
- В конце формирует сравнение показателей до и после оптимизации

## Предупреждение

Все команды выполняются на вашем устройстве на свой страх и риск.

Промпт предусматривает сохранение исходного состояния и возможность отката, но не гарантирует отсутствие ошибок на любой модели телевизора.

Проверяйте предлагаемые изменения и сохраняйте файлы восстановления.
